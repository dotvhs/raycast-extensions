# MeTube

Download and manage videos from YouTube and other services through yt-dlp using MeTube.

### Current features:

- Set default settings for Format and Quality
- Quickly add your clipboard to MeTube
- Add a link through a form, specifying Format and Quality
- List your downloads with progress
- Manage your files, copy/paste them, QuickLook support
